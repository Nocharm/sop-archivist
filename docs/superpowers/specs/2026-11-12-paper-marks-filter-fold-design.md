# 용지 표시 정리 — 번호·언어·보류·짝, 상태 칩, 필터 접기 (2026-11-12)

> **일부 대체됨**: 3px 언어 막대와 목록·개요·관리의 언어 이름표는 v0.16.6(언어 축)에서 걷었고, 용지의 언어 표시는 v0.16.7·v0.16.9의 "올리거나 고르거나 포커스할 때만 상자 위 테두리의 KO·EN 탭(KO 파랑·EN 초록)"으로 바뀌었다 — 지금 규칙은 제품 명세 §6.5. 이 문서에서 살아 있는 것은 절 번호 칸·보류 칩·짝 카드·문장 앞 번호 숨김·상태 칩 한 벌·필터 접기·첫 진입 All이다.

Split·Assign 용지 왼쪽에 붙은 색 탭(`.strip-tab`) 하나가 절 번호·언어·보류를 겹쳐 보이고 있다. 필요 이상으로 크고 화면에 어울리지 않으며, 같은 뜻(언어·보류·상태)이 화면마다 다른 모양이다. 이 문서는 그 표시를 작게 왼쪽에 모아 한 모양으로 통일하고, 상태 표시를 칩 한 벌로 바꾸고, Assign 필터를 걸면 용지가 해당 문장 위주로 접히게 하는 설계다. 시안은 사용자와 HTML로 맞췄다(이 문서의 "시안" = 그때 확정한 ④·P2·을·F3).

## 1. 왜

- 탭이 크고 튄다. 바탕 전체를 언어 색으로 칠하고 보류는 그 위 빗금이라, 줄을 훑는 눈을 끈다.
- 절 번호가 두 번 보인다 — 탭 안 `1.1.1`과 문장 원문 첫머리 `1.1.1 장비 점검`.
- 같은 뜻이 여러 모양이다 — 용지는 색 탭, Assign 카드는 색 글자 칩(`.ptag`), Split 오른쪽 칸·개요는 테두리 글자(`.lg`), 상태는 알약(`.pill`, `.fpill`).
- 오른쪽 끝(확인 ✓·AI ✦·연결 배지)은 이미 붐빈다 — **새 정보는 왼쪽에만 둔다(사용자 결정)**.
- Assign 필터는 지금 다음·이전 이동과 수만 바꾸고 용지는 그대로라, 보류 2개를 보려 해도 문서 전체를 훑어야 한다.

## 2. 목표 / 비목표 / 반목표

목표
- 용지 줄 왼쪽: [절 번호 칸][3px 언어 막대][조각]. 보류는 글 첫머리 칩.
- 문장 원문 앞 절 번호는 화면에서 숨긴다(번호 칸이 대신 보인다).
- 한/영 짝은 한 카드 + 이어 붙은 두 색 막대(P2).
- 언어 표시·상태 표시는 어느 화면에서나 한 모양.
- Assign 필터를 걸면 맞는 문장만 제 모양, 바로 앞뒤는 한 줄, 먼 것은 묶어 접기(F3).

비목표
- 원문 데이터(`source_blocks.text`, Unit 글)·결과물 Excel·A/B/C 글은 바꾸지 않는다. 번호 숨김은 표시만이다.
- 묶음 상태(`BundleStatusPill`)·문서 상태(`DocStatusPill`)·시스템 보류 알약(`pill warn`)은 그대로 알약이다 — 칩 한 벌은 Unit 배정 상태 네 가지만.
- Split에는 상태 필터가 없다. 필터 접기는 Assign 왼쪽(Old) 용지만.
- 오른쪽 끝 아이콘·연결 배지 자리는 바꾸지 않는다.

반목표(이렇게 되면 실패)
- 오른쪽 끝에 정보가 더 늘어난다.
- 번호를 숨긴 탓에 Split에서 나눌 자리(글자 위치)가 어긋난다.
- 필터를 건 채 확정·보류하자 그 문장이 바로 사라져 손이 갈 곳을 잃는다.
- 짝 두 줄 중 어느 줄이 KO인지 EN인지 놓친다.

## 3. 확정한 모양 (사용자 결정)

### 3.1 용지 한 줄 (④)

```
[번호 칸][막대 3px][ 조각: (HOLD 칩) 글 …            (끝 아이콘) ]
   5.1    ▌        [ ⏸ ON HOLD  장비 점검                     ✓ ]
```

- **번호 칸**: 조각 밖 왼쪽, 오른쪽 맞춤 mono 회색 글자(`--ink-3`, 11px). 절의 첫 블록에만 번호, 나머지 줄은 빈 칸. 칸 폭은 지금 탭 폭 규칙(`PILL_WIDTH_BY_LEVEL`, 깊이별, 번호 없는 줄은 앞 줄 폭)을 그대로 이어 받아 깊이가 들여쓰기로 읽힌다. 1280px 미만 Split에서는 번호 칸과 막대를 합친 앞머리 전체를 46px(번호 칸 38px)에서 멈춘다 — 번호 칸만 46px이면 긴 문단 글 상자가 340px 밑으로 내려간다(구현 때 결정). 넘치면 말줄임, 올리면 전체 번호가 툴팁으로.
- **언어 막대**: 3px, 둥근 끝, KO = `--lang-ko`, EN = `--lang-en`, 언어 없음(neutral) = 옅은 회색. 조각 높이 전체.
- **보류**: 글 첫머리 상태 칩(아래 3.4의 ON HOLD 칩 작은 판). 막대·번호에는 섞지 않는다.
- 탭에 올리면 번호 대신 `KO`·`H` 글자가 뜨던 동작은 없앤다. 대신 번호 칸·막대에 툴팁("한국어 · 보류" 같은 설명, 기존 `describeTab` 글을 재사용).
- 탭을 눌러도 줄이 골라지던 동작은 번호 칸·막대 자리가 이어 받는다(커서 pointer, 같은 선택 처리).
- 짝을 고르면 짝 조각의 탭에 두르던 2px 강조 테두리는 짝 카드 테두리로 옮긴다.

### 3.2 문장 앞 번호 숨김

- 줄이 절의 첫 블록이고 그 블록 글이 그 절 번호(`getSectionPill`로 읽은 숫자 번호)로 시작하면, 번호와 뒤따르는 공백·점을 화면에서 뺀다. 예: `5.1 장비 점검` → `장비 점검`, `5. 시험 절차` → `시험 절차`.
- **표시만**: 원문은 그대로. Split의 나눌 자리 계산은 지금처럼 `data-start` + 글자 노드 위치로 원문 위치를 읽으므로, 숨긴 앞머리는 그리지 않고 첫 조각의 `data-start`를 숨긴 길이만큼 미룬다. 숨긴 앞머리 안을 자르는 자리는 고를 수 없다(받아들임).
- 번호가 숫자가 아니면(제목 글자·`가.`·`(a)` 등) 숨기지 않는다 — 번호 칸에도 안 나온다(지금 규칙과 같음).
- 적용 곳: Split 용지, Assign Old 용지(같은 `paper.tsx`). Assign New 칸은 3.5.

### 3.3 한/영 짝 (P2)

- 이웃한 짝 두 줄 = 한 카드. 안쪽 구분은 점선 한 줄(지금 가는 실선 대신), 카드 바탕은 지금처럼 아주 옅은 강조색.
- 막대는 두 색이 끊김 없이 맞붙는다 — 위 줄 높이만큼 위 줄 언어색, 아래 줄 높이만큼 아래 줄 언어색. 줄 높이가 달라도(한 줄 / 두 줄) 각 줄 높이를 따른다.
- 번호 칸은 위 줄 기준(지금 `bracket="bottom"`이 위 줄 폭을 따르는 규칙 그대로).
- 보류 칩은 보류인 줄 각각의 글 첫머리.
- 짝 사이 틈(`strip-gap[data-pair]`)·합치기 버튼 동작은 그대로.

### 3.4 상태 칩 한 벌 (을)

Unit 배정 상태 네 가지(`unassigned`·`ai_suggested`·`on_hold`·`confirmed`)와 필터의 `all`을 같은 칩으로 그린다.

- 칩: 작은 각진 상자(모서리 `--r-1`), mono 굵은 대문자 글자, 왼쪽 아이콘(지금 아이콘 그대로: Circle·CircleDashed·CirclePause·CircleCheck, `all`은 ListFilter).
- 색: 미배정 = 회색 글자 + 옅은 바탕 + 안쪽 테두리, AI = `--st-ai-ink` 글자 + AI 옅은 바탕, 보류 = `--st-hold-ink` + 보류 옅은 바탕, 확정 = 강조색 + 강조 옅은 바탕. 색만으로 구분하지 않게 아이콘·글자는 늘 함께.
- 글자: 지금 i18n 상태 이름(`status.unit.*` — 영어 고정)을 그대로 쓰고 대문자는 CSS로만(`text-transform`) — DOM 글자가 그대로라 사용 설명서의 굵은 라벨 대조가 깨지지 않는다.
- 크기: 표·줄 머리용 18px. **필터 칩만 누르는 단추라 26px**, 고르면 꽉 찬 색(바탕 = 그 상태 진한 색, 글자 = 바탕 반대색), 수는 옅게 뒤에.
- 용지의 보류 칩은 같은 칩의 작은 판(15px, 아이콘 + 글자).
- 바꿀 곳: `UnitStatusPill`(Assign 줄 상태, 결과물 A 상태 열) → 칩 부품, Assign 필터 줄(`.fpill` + `FILTER_LOOK`) → 칩 필터. 둘이 한 부품(또는 한 CSS 계열)을 쓴다.
- 라이트·다크 모두 글자 대비 4.5:1(`pw-contrast-audit`). 고른 필터 칩의 반대색 글자도 포함.

### 3.5 Assign New 칸

- 같은 [번호 칸][막대][조각] 모양, 짝은 P2. New 문장에는 보류가 없어 칩 없음.
- 지금 절 머리 줄(`.new-sec`, 예 `3.2 시료 시험`)이 따로 떠 있어 번호 칸과 겹친다 → **절 머리 줄 글에서 앞 번호를 빼고**(`readSectionNumber`로 읽은 번호), 번호는 번호 칸에만. 번호가 없는 절 머리는 그대로.
- 언어 차단(`data-blocked`)·고름·후보 상태 표시는 그대로.

### 3.6 작은 언어 표시 통일

용지 막대와 같은 모양의 작은 판 = **[3px × 13px 막대][mono 글자 KO/EN]**, 글자는 회색(`--ink-2`), 색은 막대만. neutral은 `–` 글자 + 회색 막대.

- Assign 행선지 카드·근처 목록(`.ptag`, `assign/page.tsx`)
- Assign 행선지 나무(`destination-tree.tsx`)
- Split 오른쪽 칸 Unit 상태 줄(`split/page.tsx`의 `.lg`)
- 묶음 개요 언어별 진행 이름표(`bundles/[id]/page.tsx`의 `.lg`) — 통계 이름표지만 맞춘다(내 판단).
- 묶음 목록(`app/page.tsx`의 `.lg` 언어 표시)
- Assign 오른쪽 칸 고쳐 쓰기 칸의 언어(`assign/page.tsx`의 `slot.lang` `.lg`)
- `.lg` 정의는 지우지 않는다 — Split 오른쪽 칸이 언어가 아닌 순번(`index + 1`)에 쓰고 있다. 언어로 쓰는 곳만 새 부품으로 바꾼다.

### 3.7 도움말 범례

Split·Assign Help → Marks의 견본(`split-help.tsx`·`assign-help.tsx`의 `strip-tab swatch`)을 새 표시로: KO 막대, EN 막대, ON HOLD 칩, 짝(두 색 막대), Assign은 상태 칩 네 개.

## 4. 필터 접기 (F3, Assign Old 용지)

### 4.1 무엇이 보이나

필터가 `all`이 아니면 Old 용지의 Unit(조각·짝 카드·표 = 지금 용지 조각 단위)을 셋으로 나눈다.

1. **맞음** — 필터 목록에 든 Unit: 제 모양.
2. **곁** — 맞음의 바로 앞 또는 바로 뒤 Unit(같은 부분 Body/Header/Footer 안, 문서 순서): **한 줄 판** — 번호 칸·막대는 남기고(옅게), 조각은 한 줄 말줄임 옅은 작은 글(11.5px, `--ink-4`), 테두리·그림자 없음. 짝이면 두 줄 글을 ` / `로 이어 한 줄. 표·그림은 "표"·"그림" 한 줄.
3. **멀다** — 나머지: 이어진 것끼리 **묶음 한 줄** — 점선 테두리 낮은 막대에 `⋯ 문장 N개 § 5.1–5.2`(그 묶음이 걸친 절 번호 처음–끝, 하나면 하나) + 오른쪽 "펼치기". 묶음이 한 개뿐이면 접지 않고 한 줄 판으로.

맞는 Unit이 하나도 없으면 용지 대신 빈 상태 글(그 필터에 해당 문장이 없다).

### 4.2 누르면

- 묶음 한 줄 → 그 묶음의 Unit들이 한 줄 판으로 펼쳐지고 그 위에 "접기" 손잡이.
- 한 줄 판 → 제 모양으로 펼친다(**엿보기**). 엿보기 조각은 바탕을 가라앉히고(`--sunken`) 테두리 점선으로 "필터 밖"을 보인다.
- 엿보기 조각은 보통 조각과 똑같이 동작한다(누르면 고르고, 배정할 수 있다) — 내 판단: 앞뒤를 보다가 바로 그 문장을 손볼 수 있어야 해서. 그래서 엿보기 조각을 눌러 다시 접지는 않는다.
- 다시 접기: 묶음의 "접기" 손잡이는 그 묶음 전체(안의 엿보기 포함)를 묶음 한 줄로 되돌린다. 고른 조각이 그 묶음 안에 있으면 고른 조각만 엿보기로 남고 그 앞뒤가 각각 묶음 한 줄로 접힌다(저절로 엿보기도 같은 모양 — 큰 묶음 전체를 펼치지 않는다). **필터를 바꾸거나 같은 필터를 다시 누르면 모든 펼침이 접힌다**(펼침 상태는 필터마다 새로 시작).
- 한 줄 판을 누르면 펼치기만 하고 고르지는 않는다.
- 키보드: 한 줄 판·묶음 한 줄은 단추라 Tab으로 가서 Enter/Space로 펼친다. 다음·이전(지금 글쇠)은 필터 목록(스냅숏)만 밟는다.
- **필터 밖 Unit이 골라질 때**(New 문장 출처 칩 → `jumpToOld` 등): 그 Unit이 묶음·한 줄 판 안이면 저절로 엿보기로 펼친 뒤 고르고 스크롤한다(지금 `findOldStrip`이 접힌 조각을 못 찾고 조용히 포기하는 일을 막는다).
- 엿보기 조각을 고른 채 다음·이전을 누르면 목록 맨 앞이 아니라 **문서 순서로 그 자리 다음(이전)의 맞음**으로 간다(지금은 `listKeys.indexOf`가 -1이라 맨 앞으로 간다).

### 4.2a 지금 문서·부분에 맞는 것이 없을 때

Old 칸은 한 번에 문서 하나·부분(Body/Header/Footer) 하나만 보이는데 필터 목록은 묶음 전체에 걸친다. 지금 문서·부분에 맞는 Unit이 0개면 용지 대신 빈 상태 글 + "맞는 문장이 있는 곳" 바로 가기(문서·부분 이름과 수, 누르면 그리로 옮긴다)를 보인다. 저절로 옮기지는 않는다(보던 자리를 빼앗지 않게). 문서 선택기·부분 탭에 수를 붙이지는 않는다 — 내 판단, 범위를 늘리지 않으려고.

### 4.2b 출처 없는 New 문장 모드

필터 줄의 `assign-filter-unsourced`(출처 없는 New 문장 고르기)는 Old 조각을 눌러 출처로 잇는 모드라 Old를 넓게 훑어야 한다 → **이 모드에서는 접지 않는다**(용지 전부). 칩 모양은 같은 한 벌의 위험 색(`--danger-ink`·옅은 위험 바탕) 칩.

### 4.3 목록은 걸 때 고정

지금 Assign은 필터를 걸 때의 목록을 스냅숏(`snapshot.keys`)으로 잡아, 확정·보류로 상태가 바뀌어도 목록이 그대로다. 접기도 **이 스냅숏을 기준**으로 한다 — 보류 필터에서 보류 문장을 확정해도 그 자리에서 사라지거나 접히지 않는다(칩만 CONFIRMED로 바뀐다). 필터를 다시 누르면 새로 계산.

### 4.4 처음 들어올 때

Assign에 들어오면 필터는 **`all`**(용지 전부, 안 접힘)로 연다 — 사용자 결정(2026-11-12). 지금 `pickFirstFilter`가 첫 필터(보통 Unassigned)를 고르던 첫 진입 규칙을 바꾼다. 다음·이전도 그래서 처음엔 전체 목록을 밟는다. 감사 스크립트·설명서 그림의 기준 상태도 `all`이다.

### 4.5 짜임

- 접기 분류(맞음/곁/멀다, 묶음 나누기, 묶음 절 범위)는 순수 모델 `frontend/src/lib/paper-fold-model.ts`(이름은 빌더 재량)로 떼어 단위 테스트한다. 입력 = 문서 순서 Unit id 목록(부분별), 맞는 id 집합, 펼친 묶음·엿보기 id 집합, Unit별 절 번호 → 출력 = 그릴 항목 목록.
- `paper.tsx`는 `strips`에 선택적 `fold`(맞는 id 집합 + 펼침 상태 + 콜백)를 받는다. 없으면 지금처럼 전부 그린다 — Split은 넘기지 않는다.
- 화면 밖 조각을 그리지 않는 `content-visibility` 규칙과 수천 Unit 성능을 지킨다(묶음은 한 줄이라 오히려 가벼워진다).

## 8. 내가 정한 것(사용자 확인 전)

- 번호 숨김은 표시만(원문·결과물 불변).
- New 칸 절 머리 줄에서 번호를 빼고 번호 칸에만.
- 묶음 개요 언어 이름표도 새 언어 표시로.
- 상태 칩 글자는 기존 상태 이름 + CSS 대문자.
- 엿보기 조각은 보통 조각처럼 고르고 배정할 수 있다.
- 한 개짜리 묶음은 접지 않는다.
- 필터 밖 Unit으로 건너뛰면 저절로 엿보기, 엿보기에서 다음·이전은 문서 순서로 가까운 맞음.

- 출처 없는 New 문장 모드에서는 접지 않음, 그 칩은 위험 색.
- 언어 표시 통일에 묶음 목록·Assign 고쳐 쓰기 칸까지 넣음.
