# 원본 보기 — Assign Space 시트의 인쇄 미리보기 설계 (2026-11-27)

> 상태: **사용자 승인 2026-11-27**(§7의 만드는 사람 몫 · 쪽 나누기 문단 단위 · 다크에서도 흰 종이 · 칸 폭 배율만 · 머리 줄 반복은 문서 설정대로 · EMF 빗금 1차 포함). 실측 스크립트는 저장소 밖 `~/Documents/sop-orchestration/original-view-spike/`. 시안 두 장(Space 시트 탭 · 움직임 시연)과 실측(스파이크)은 세션에서 HTML로 보았다. 끝나면 지우고 인용되는 절만 `docs/architecture/decisions.md`로 옮긴다(`documentation.md`).

## 1. 왜

Assign에서 Old · New 박스를 고르며 일하다가 **그 문단이 실제 문서에서 어떻게 생겼는지**(어느 쪽, 표 안인지, 앞뒤, 글꼴 · 들여쓰기, 문장 중간의 버튼 아이콘) 보고 싶을 때가 있다. 지금 용지는 추출한 글을 박스로 보일 뿐 원본 모양이 없다. 원본 파일을 따로 열면 고른 자리를 다시 찾아야 한다.

**목표**: Space 시트에서 탭 하나로 **인쇄 미리보기처럼** 원본을 보고, 고른 박스를 따라 그 문단으로 간다.

**성공**: Word로 만든 실제 SOP에서 종이 크기 · 여백 · 글꼴 · 표 · 머리말/꼬리말 · 그림 · 쪽 나눔이 인쇄한 것과 거의 같고, 박스를 옮기면 원본이 그 자리로 따라가며, Assign 글쇠 반응이 느려지지 않는다.

## 3. 하지 않는 것

원본 편집 · 인쇄 기능 자체 · Word와 픽셀 일치 · 서버에서 PDF로 바꾸기(배포 서버는 PyPI · npm 밖 내려받기가 막혀 있고 메모리 2G — LibreOffice를 들일 수 없다) · PDF 원본 그리기(2차, pdf.js) · 쪼개기 화면의 원본 보기(2차).

**실패로 보는 것**: 원본 탭 때문에 Assign 글쇠 반응이 눈에 띄게 늦어지는 것, 원본 그리기가 앱 화면 CSS를 흔드는 것, 올린 문서 안의 링크 · 스크립트 성분이 앱에서 동작하는 것.

## 4. 방식 — 견준 셋

| 방식 | 판단 |
|---|---|
| **A. 브라우저가 원본 DOCX를 그린다**(npm `docx-preview` 0.4.1 + `jszip` 3.10.2) + 앱이 쪽을 나눈다 | **고름.** 글꼴 · 표 · 그림 · 머리말이 문서 스타일대로, 서버 일이 작고 서버 메모리를 안 쓴다, npm이라 서버 빌드 규칙에 맞는다. |
| B. 서버에서 PDF로(LibreOffice) → pdf.js | 가장 정확하지만 배포 제약(외부 설치 금지 · 이미지 수백 MB · 메모리 2G)과 정면 충돌. |
| C. 추출 자료로 인쇄 모양을 다시 그림 | 자리 찾기는 완벽하지만 글꼴 · 들여쓰기 · 표 테두리가 없어 "실제 모양"이 안 된다. |

### 실측(스파이크, 합성 SOP를 1~60배로 불림, Chrome, 세 번 잰 가운데 값)

| 문서 | 문단 · 칸 | 표지 심기 + 그리기 + 첫 화면 | 같은 것, CPU 4배 느리게 | 쪽 나누기(앱) | 표지 적중 |
|---|---|---|---|---|---|
| 1배 | 51 | 65ms | 160ms | — | 100% |
| 30배 | 1,530 | 130ms | 0.5초 | — | 100% |
| 60배(180쪽) | 3,060 | 220ms | 0.85초 | 24ms / 4배 93ms | 100% |

- 고름 따라가기(표지 찾기 + 굴리기 + 칠): 가장 느린 경우도 1ms 안. 그리개 코드 압축 약 50KB.
- 종이 크기 · 여백은 문서 값 그대로(Letter → 816×1056px, 여백 96px). Word 쪽 나눔 표시(`w:lastRenderedPageBreak`)가 있으면 쪽이 정확히 한 장 높이로 끊긴다. 없으면 직접 넣은 쪽 나눔까지 한 장이 길게 이어진다 — 그래서 §5.3.
- 지저분한 문서(문장 중간 글자 크기 아이콘 · 오른쪽에 떠 있는 그림 · 글상자 · 병합 표 칸 아이콘): 아이콘과 떠 있는 그림 · 병합 칸은 제 모양. 글상자는 글만 나오고 상자 테두리 · 위치가 빠진다. 글상자 안 문단의 표지는 Word가 두 벌 저장한 것 중 그리개가 그리지 않는 쪽에 심겨 빗나갔다(§5.2에서 두 벌 모두).
- 그리개는 EMF · WMF 그림을 다루지 않고 브라우저도 못 그린다(옛 아이콘 · 붙여 넣은 Visio · Excel 개체의 미리보기) — §5.5.
- 변경 내용 추적이 남은 문서는 이미 업로드에서 거절된다(`tracked_changes`).
- 한계: 합성 문서라 그림이 적고 머리말이 없다. 실제 문서는 사용자가 PC에서 점검 페이지(오프라인)로 본다.

## 5. 설계

### 5.1 서버 — Unit → 원본 자리

- `GET /api/bundles/{id}/documents/{doc_id}/original-places` (구성원, 읽기만). 원본 탭을 처음 열 때 한 번 받는다 — Assign 첫 읽기(`/view`)에 얹지 않는다.
  - 응답: `{ file_format, page_basis, places: [{ unit_id, blocks: [{ path, page }] }] }` — 지금 추출의 살아 있는 Unit마다, 그 Unit의 범위(`spans`)가 걸친 블록을 범위 순서대로 중복 없이. `path`는 `source_blocks.xml_path`, `page`는 `source_blocks.page`(본문 밖은 null).
  - 원본 파일이 없거나(앱에서 만든 문서) PDF면 `places`는 비우고 `file_format`으로 화면이 안내한다.
  - 원문 글자는 싣지 않는다(위치만).
- `GET …/file` 응답에 캐시 머리: `ETag`(문서 `sha256`) + `Cache-Control: private, max-age=86400` — 같은 문서 id의 바이트는 바뀌지 않는다. `If-None-Match`가 같으면 304.
- 거절 코드 · 권한 · env · Alembic 변경 없음.

### 5.2 화면 — 원본 그리기(`components/assign/original-view.tsx` + 순수 모델)

- 그리개(`docx-preview` · `jszip`)는 원본 탭을 처음 열 때 `import()`로 불러온다.
- **표지 심기**(순수 모델 `lib/original-place-model.ts`): 원본 `word/document.xml`(머리말 · 꼬리말 · 각주 부분은 그 부분 파일)을 DOMParser로 읽고, `path` 조각(`tag[n]` = 같은 태그 형제 중 n번째)을 따라 요소를 찾는다. 요소마다 자식 목록을 한 번만 훑어 둔다(처음 짠 방식은 60배에서 0.5초였다).
  - `txbx[n]`은 추출기가 붙인 글상자 순번 — `mc:Choice` 쪽 n번째 `txbxContent`, 같은 자리의 `mc:Fallback` 사본에도 같은 표지를 심는다.
  - 표 칸(`tc`)이면 칸의 첫 문단에, 그 밖은 문단(`p`)의 첫 자리(`pPr` 다음)에 `w:bookmarkStart`(이름 `sopa_<n>`, id는 문서 안 기존 id와 겹치지 않는 큰 수).
  - 줄인 경로(`/…/`)나 못 찾은 경로는 물러나기: 가장 가까운 상위 요소 → 그 블록의 쪽 머리 → "이 줄은 원본 자리를 못 찾았어요".
  - 그리개는 책갈피를 `<span id=…>`로 그린다 — 표지 id로 요소를 찾는다.
- **안전**: 원본 글은 그리개가 DOM으로 만든다(HTML 문자열을 끼우지 않는다). 그린 뒤 `<a href>`는 `http(s):` · 문서 안 `#`만 남기고 지운다. 그리개의 `<style>`은 원본 칸 안 컨테이너에만 넣고 클래스 접두를 따로 준다(앱 CSS와 섞이지 않게). `src/source-rules.test.ts` "one path per concern" 허용 목록에 사유 한 줄.
- 같은 문서는 다시 그리지 않는다 — 탭을 바꾸거나 시트를 닫아도 그린 원본은 문서가 바뀔 때까지 숨겨 둔다(`<Activity>`). 문서가 바뀌면 버린다.

### 5.3 인쇄 미리보기 — 쪽 나누기

- 그리개 옵션: `breakPages: true`, `ignoreLastRenderedPageBreak: false`(Word 표시를 따른다), 머리말 · 꼬리말 · 각주 · 미주 그림.
- 그린 뒤 **쪽 나누기**(순수 셈은 모델, DOM 옮기기는 부품): 장(`section.docx`)의 본문(`article`) 아이들을 흐름 위치(`offsetTop + offsetHeight`, 떠 있는 요소는 빼고)로 재서 종이 높이 − 위 · 아래 여백을 넘는 첫 아이부터 새 장으로 옮긴다. 새 장은 장을 얕게 복제하고 머리말 · 꼬리말을 복제한다. 표가 넘치면 넘치는 줄부터 새 표(같은 열 머리 · 열 폭)로. 한 장보다 큰 덩어리 하나는 그대로 둔다(그 장만 길다). 아래쪽 여백 몇 px의 넘침은 넘침으로 보지 않는다.
  - 스파이크: 180쪽에 24ms(4배 93ms), 나눈 뒤에도 표지 100%. 고칠 것 두 가지 — 떠 있는 글상자의 바깥 상자 높이로 너무 일찍 끊기는 것(흐름 위치로 재기), 문단 아래 여백 4px 넘침(허용 폭).
  - 문단 중간에서 줄 단위로 나누기는 하지 않는다(문단 하나는 통째로 다음 장) — 쪽 끝 한두 줄이 Word와 다를 수 있다.
- 쪽 번호: 머리말 · 꼬리말의 PAGE · NUMPAGES 필드 결과를 그리기 전에 표지 글자로 바꿔 두고 나눈 뒤 그 장의 번호 · 전체 장 수로 채운다.
- 보기: 회색 책상(토큰), 종이 그림자 · 틈, 칸 폭에 맞춘 배율(CSS `zoom`, 종이가 칸보다 좁으면 1배), 오른쪽 아래 쪽 칩 "3 / 12"(굴릴 때 바뀐다). 다크 테마에서도 종이는 흰색(인쇄 모양).

### 5.4 따라가기 · 움직임

- 고른 박스(쪽마다: Old는 `pickedBoxId`, New는 New 고름)의 Unit → `places`의 블록들 → 표지 → 칠할 요소(칸이면 `td`, 아니면 문단). 첫 블록을 가운데로.
- 거리별 움직임(D8)의 판정은 순수 모델(`readFollowMotion(지금 굴림, 대상 위치, 화면 높이, 반복 중, 움직임 줄이기)` → `none | smooth | fade | instant`), 굴림 · 흐림은 공용 훅 하나(`lib/use-original-follow.ts`) — 화면 파일의 이펙트 기준선은 늘리지 않는다. 그리는 중에 고름이 바뀌면 다 그린 뒤 마지막 것으로.
- 칠 · 번쩍임 · 흐림은 CSS(토큰 색), 움직임 줄이기면 없음.

### 5.5 못 보이는 경우

- PDF 원본: "PDF 원본은 아직 여기서 보이지 않아요" + 파일 받기 단추.
- 원본 파일 없음(앱에서 만든 New): "이 문서는 앱에서 만든 문서라 원본 파일이 없어요".
- **EMF · WMF 그림**: 그리개가 만든 `<img>` 중 못 그린 것은 원래 크기의 빗금 상자 + "미리보기 불가(EMF)" 글로 바꾼다. EMF를 직접 그리는 npm 그리개(`rtf.js`의 EMFJS · WMFJS)는 사용자의 실제 문서 점검 결과를 보고 2차로 정한다.
- 그리기 실패(망가진 파일 등): 그 칸에 다시 시도 + 파일 받기.

### 5.6 Space 시트(`components/assign/space-preview.tsx` · `lib/space-preview-model.ts`)

- 상태 기계에 `closing`(열어 둔 시트의 짧은 탁 뒤) 한 단계: 그동안 시트는 흐려지며 내려가고, CSS 움직임이 끝나면(`animationend`) 닫힘 — 타이머를 새로 쓰지 않는다. `closing` 중 Space 내림 → 탭 바꾸고 `kept`. 움직임 줄이기면 0.3초 동안 투명도만.
  - 두 번 탁 간격 상수 `DOUBLE_TAP_MS = 300`(움직임 길이와 같은 값, CSS 변수로 넘긴다).
- 머리: 탭 두 개(`role="tablist"`, 탭마다 testid), 그 옆은 지금처럼 고른 줄 · 상태. 받기 단추는 결과 미리보기 탭에서만.
- 탭 기억은 `lib/assign-view-prefs.ts`(`readSpaceTab` · `writeSpaceTab`).

### 5.7 같이 고치는 곳

- i18n en · ko(탭 이름 · 안내 · 못 보임 · 쪽 칩), 사용 설명서 Space 절 글(그림은 정식 업데이트 때), `docs/qa/feature-map.md` Assign Space 줄, 스모크: 탭 바꾸기 · 두 번 탁 · 기억 · 원본에서 고른 문단 칠 · 양단 두 원본 · 쪽이 종이 높이.
- 연습 화면(`/practice`) 가짜 서버: 새 조회 경로를 `practice-server.ts` `ROUTES`에 — 연습 문서는 원본 파일이 없어 "원본 파일 없음" 안내(빠뜨리면 Not available).
- 새 npm 의존성 둘은 `frontend/package.json`에 정확한 버전과 왜(`dependencies.md`).
