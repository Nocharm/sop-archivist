# v0.14 사용 피드백 21건 — 설계

> 상태: 사용자 승인 2026-11-11(시안 페이지 검토 뒤 "ㅇㅋ 착수"). 시안: 세션에서 공유한 HTML(저장소 밖). 결정이 비어 있던 질문은 시안의 기본안·추천안으로 확정했다 — 아래 **결정** 표에 "내 판단"으로 표시.

## 왜

v0.14.0을 실제로 써 본 첫 피드백. 문서 → 쪼개기 → 배정 화면에서 혼동을 주는 입구를 걷어내고(New 업로드), 원문 용지가 문장 시작을 가리거나 산만한 곳(언어 태그·짝 색·간격)을 정리하고, 손이 많이 가는 조작을 줄인다(우클릭 메뉴·문장 단위 AI 나누기). 서버 쪽은 영어가 먼저 오는 번갈아 문서의 자동 짝 어긋남 하나.

## 목표 / 비목표

- 목표: 아래 21건을 화면과 설명서(`frontend/public/manual/user-manual.md`)에 반영. 기존 사람 경로·AI 꺼짐 경로는 그대로 돈다.
- 비목표: 새 권한·새 env·DB 스키마 변경 없음(필요해지면 멈추고 묻는다). 본문 폰트(Pretendard)·원문 용지 폰트는 바꾸지 않는다.
- 반목표: 피드백에 없는 화면 재배치, 서버 API 모양 변경(15번의 기존 `unit_id` 요청 재사용 외).

## 항목별 동작

### 문서 화면
1. **업로드 창**: Old/New 카드 고르기(`SideChoice` → 변경: 컴포넌트째 제거)와 New 전용 입력(Doc type·Parent code)을 없애고 Old 전용으로. New(이미 쓴) 문서는 **To-Be 목록의 문서 줄마다 "Upload written" 단추**로 올린다 — 그 줄이 `target_doc_id`이므로 서버 `POST /bundles/{id}/documents`(`side=new`)에 줄의 doc_type·parent_code를 그대로 싣는다(서버가 요구하는 필드는 구현 때 `api-sop.ts`·라우터를 보고 맞춘다). → 변경: 줄마다가 아니라 To-Be **목록 단위** 업로드로 출시(사용자 판정). 컴포넌트는 `UploadWritten`. 이미 올린 New 문서는 문서 목록에 계속 보인다. 쪼개기 경계 미확인이 남았으면 To-Be 업로드 곁에 "Old 쪼개기를 먼저 끝내길 권합니다" 한 줄.
2. **번갈아 그림**: `layout-picto` 4줄을 고정 높이 줄 + 세로 가운데 정렬로, 라벨과 상자 중심 맞춤.
3. **MorphButton 묶음(`.mbtn-set`)**: 하나를 올리면 나머지는 폭 0으로 접히고(투명만이 아니라 자리를 내줌) 올린 단추가 묶음 폭 전체로 펼쳐진다. 공통 규칙이라 같은 묶음을 쓰는 모든 곳이 바뀐다 — `pw-overlap-audit.mjs`로 확인.
4. **언어 배치 Select(문서 표)**: 고정 폭(그림+글자+화살표), 넘치면 말줄임 + 툴팁, 화살표 상시 표시(호버 때 글자 밀림 없음). 공통 `Select`에 고정 폭 옵션을 더하고 이 칸에서 쓴다.
5. **좁은 폭(<1230px) 합친 칸**: 머리 "Extraction · Aux check · Warnings". 첫 줄에 추출·보조 검사·경고(개수 칩, 툴팁으로 목록) 한 줄, 둘째 줄에 액션 묶음 왼쪽 정렬.

### 폰트
6. `fonts.ts` `fontAccent`를 IBM Plex Sans KR(굵기 2벌, 저장소에 woff2 + OFL 라이선스, `licenses/README.md` 갱신)로 교체 → 변경: Paperlogy 600 한 벌로 교체하고 Gmarket(ArchivistAccent) 파일과 세로 보정 값은 걷어낸다. 디자인 기초 문서의 글꼴 표도 갱신. 대비·겹침 감사 다시.

### 쪼개기 — 용지
7. **틈**: 평소 4px, 고른 문장의 위아래 틈·호버한 틈은 12px(전환 애니메이션, reduced-motion 존중).
8. **합치기 단추**: 틈 가운데 → 문장 글 시작 x 위치에 왼쪽 정렬.
10. **나눌 선 툴팁**: 선 위쪽에 띄워 아래 "Split here / Cancel" 창과 겹치지 않게.
12. **경계 확인 단추**: 체크 → ↵ 글쇠 모양(오른쪽 칸 단추와 같은 기호), 문장 끝에서 간격을 두고, 호버 때 라벨 펼침 유지.
13. **짝**: 짝 두 줄 사이 틈 1px, 둘을 감싸는 얇은 왼쪽 괄호선 하나, 바탕 아주 옅게(지금 AI 보라 바탕·3px 막대 대체). 짝이 이웃하지 않을 때(사이에 다른 줄)는 각 줄에 괄호선만.
14. **필 칸**(→ 변경: 사용자 피드백 세 차례를 거쳐 오른쪽 칸이 아니라 **조각 왼쪽 밖의 탭**(Task 5c) — 언어 색 탭, 폭은 절 깊이, 번호는 첫 조각 탭에만, 한/영 짝은 이어 붙은 탭 하나. 합치기 알약은 평소에 숨기고 틈을 올릴 때만 보인다): 언어 태그를 문장 왼쪽 위 겹침에서 **오른쪽 고정 폭 칸**으로 옮긴다. 폭은 `11.11.1.1.1`(5단계)이 안 잘리는 값으로 고정, 문장 글은 그 칸 앞에서 줄바꿈. `section_label`이 없으면 지금 글자 태그(KO/EN/H, duo 포함). 있으면 번호 필 하나 — 바탕은 언어 색(짝이면 짝 순서대로 2분할, 보류까지 있으면 3분할), 호버 때 번호가 페이드아웃되며 언어 글자가 보인다. 글자색은 모든 바탕에서 4.5:1(필요하면 보류 톤 조정), 라이트·다크 모두. 서버가 Unit 응답에 `section_label`을 주지 않으면 응답 필드만 더한다(스키마 변경 없음).

### 쪼개기 — 조작
9. **우클릭 메뉴**(용지의 문장 줄): 고른 문장이 있는데 **다른 문장**을 우클릭 → 두 문장 동작(짝 만들기 — 바로 확정 / 짝 풀기 — 둘이 짝일 때 / 합치기 — 이웃일 때 / 둘 다 경계 확인). **고른 문장 자신**(또는 고른 것 없이 아무 문장)을 우클릭 → 오른쪽 칸과 같은 단일 동작(경계 확인·나누기·AI 나누기·보류·언어 KO/EN·짝 풀기). 안 되는 항목은 비활성 + 호버 때 이유 툴팁. 공통 `Menu` 부품, 키보드(Shift+F10/메뉴 키)로도 연다, Esc로 닫힌다. 규칙(가능/불가 판정·이유)은 순수 모델에 두고 시험.
15. **AI 나누기**: 문장 단위 요청(`requestAi("split", {unit_id})`, Assign이 이미 쓰는 길)을 오른쪽 칸 Text 아래 "AI split this sentence"와 우클릭 메뉴에 연다. 상단 바 단추는 "AI split whole document"로 이름을 바꿔 일괄임을 드러낸다. 결과는 오른쪽 칸 "AI suggestions" 영역에 **탭으로 쌓는다**(탭 = 문장 ID, 안 본 것 점 표시, 일괄 결과는 개수와 함께 한 그룹). 탭을 누르면 그 문장으로 이동, 미리 보기·적용·거절·다음. AI가 꺼져 있으면 단추는 비활성 + 이유. 서버가 쪼개기 쪽 문장 단위 요청을 거절하면(종류·대상 검증) 서버를 맞춘다.
16. **언어 칸 경고**: 문서 배치와 문장 언어가 어긋나면(한 언어 전용 배치인데 다른 언어 / 번갈아인데 같은 언어가 길게 이어짐 등 — 판정은 순수 모델) 언어 단추 아래 경고 한 줄과 고칠 곳(문서 화면 배치).
17. **오른쪽 칸**: 위 F 결정대로. 기존 섹션 순서·기능은 유지.

### 자동 짝 (backend)
11. `segment.py` `suggest_interleaved_pairs`가 KO→EN만 시험해 EN 먼저 문서에서 짝이 밀린다. 구간마다 KO→EN·EN→KO 두 방향으로 짝을 만들어 `_is_likely_pair` 통과 수가 많은 쪽을 채택, 동점은 문서 전체의 우세 순서로. 시험: EN 먼저 합성 문서, 섞인 순서, 첫 줄 외톨이, 기존 KO 먼저 회귀.

### 배정(Assign)
18. Old 칸 위에 쪼개기와 같은 Body/Header/Footer 탭(둘 이상일 때만).
19. **추천 칸**: 카드에 종류 아이콘(잇기·새 자리·옮기기·지우기), 제목 줄 오른쪽 유사도 값(서버가 주면 — 없으면 생략), 글 2줄 말줄임, 아래 줄에 절 번호·언어·근거 칩. 아코디언 머리(Recommendations/Nearby/All)에 아이콘·개수.
20. 항상 두 칸. 자동 열고 닫기와 "Open/Close New" 단추를 없앤다. 쓴 New가 없으면 오른쪽에 빈 안내 + "Go to To-Be".
21. **연결 표시**: Old 줄 오른쪽 필 칸에 연결 배지(→ 문서 코드). 이어진 New 문장이 오른쪽 칸에서 보이면 선(지금처럼), 화면 밖이면 배지에 ↑/↓, 누르면 오른쪽 칸이 그 문장으로 스크롤.
