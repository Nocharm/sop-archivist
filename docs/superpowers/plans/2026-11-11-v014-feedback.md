> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v0.14.0 사용 피드백 21건을 문서·To-Be·쪼개기·배정 화면, 강조 폰트, 번갈아 문서 자동 짝(서버)에 반영한다.

**Architecture:** 화면 규칙(가능/불가 판정·경고 판정·필 색 계산·연결 방향)은 `frontend/src/lib/*-model.ts` 순수 함수로 두고 vitest로 시험, 컴포넌트는 그 결과를 그린다. 서버는 `backend/app/sop/segment.py` 짝 제안 하나만 바뀐다. 새 API·스키마·권한·env 없음.

**Tech Stack:** Next.js 16 / React 19 / Tailwind 4 / vitest, FastAPI / pytest.

**Spec:** `docs/superpowers/specs/2026-11-11-v014-feedback-design.md` (결정 표 A–G·12 포함, 실행자는 반드시 함께 읽는다)

- 루트 `CLAUDE.md`·`frontend/CLAUDE.md` 체크리스트를 따른다: 새 문구는 `src/lib/i18n-messages.ts` en·ko 한 쌍, 인터랙티브 요소 `data-testid`(`surface-role`), raw hex/색 값은 `src/styles/tokens.css` 밖 금지, 다크는 토큰만, 브라우저 기본 체크박스·`title` 툴팁 금지(`Tooltip`/`useDelegatedTip`), 값 고르기는 `Select`, 메뉴는 `components/ui/menu.tsx` `Menu`.

- 커밋 메시지 `type(scope): English — 한국어`, 커밋마다 `PROGRESS.md` 1–3줄. 푸시하지 않는다(마지막 Task에서 한 번에).
